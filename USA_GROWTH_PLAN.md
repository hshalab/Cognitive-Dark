## 1. Sab se pehle: sachai samhlein

4 videos par **2 views / 0 views hona koi bug nahi, yeh bilkul normal hai.**

- Naya channel par YouTube/FB/IG pehly 24–72 ghante aapki video ko *thore test impressions* deta hai (cold start).
- Agar un impressions par **CTR (click-through-rate) ya first-3-second retention** kam hua to system video ko aur push nahi karta.
- Algorithm kisi ko "favor" nahi karta — woh sirf **signals** dekhta hai:
  1. **Click** hua ya nahi (thumbnail + title)
  2. Pehly **3 second** mein ruky ya nahi (hook + first frame)
  3. **Average view duration / retention %**
  4. **Watch time** (sab se bara signal)
  5. Shares / saves / comments (IG + FB par sab se zyada wazan)

Is liye abhi sab se zyada awsalities ki nahi, **hooks + thumbnails + consistency** ki zarurat hai.

> Aapka ML engine ab theek hai — woh sirf tab seekhna shuru kare ga jab is ke paas 30–50 videos ka data hoga. Abhi usay "exploration mode" mein rehna chahiye.

## 4. Hook writing — USA viral style (sab se zaroori skill)

CTR aur 3-second retention ka 90% inaam hooks par hai.

1. **Pattern interrupt (stop-scroll):** "Aap shayad kisi cult ka hissa ho — aur pata na ho."
2. **Knowledge gap:** "Cult leaders kabhi yeh 3 sawalon ka jawab nahi dete."
3. **Self-relevant danger:** "Agar koi yeh aik sentence bole — woh aap ko manipulate kar raha hai."

### Hook mein jo NAHI karna
- "Hello everyone" / "Welcome back" / "Today we talk about…" → foran swipe.
- Emoji ya clickbait jo content se match nahi karta.

## 6. Platform settings / API fixes (abhi karein)

### YouTube
- **Channel language:** English (US) — Settings → Language.
- **Audience:** "Not made for kids" (aapka educational adult content hai).
- **Monetization ke liye** abhi se watch-hours build karein: har 10 Shorts ke saath 1 **long-form (8–12 min)** banayein (Shorts se subscribers, long-form se watch-hours milte hain).
- Custom thumbnail ke liye **phone verify** zaroori hai (warna `thumbnails().set` 403 dega).

### Facebook
- Page category **"Education"** ya **"Media/News Company"** set karein.
- Reels upload ke liye token mein `pages_manage_posts`, `pages_read_engagement`, `publish_video` scopes hone chahiye.
- Professional mode ON karein aur monetization eligibility track karein.

### Instagram — **abhi ek masla hai**
Error aa raha tha: `(#10) Application does not have permission for this action`. Iska matlab:
1. Instagram account **Business ya Creator** hona chahiye.
2. Facebook Page se properly **linked** hona chahiye.
3. Token mein `instagram_basic` + `instagram_content_publish` scopes chahiye.
4. App **Live mode** mein honi chahiye (dev mode ke token publishing nahi karte).

Jab tak theek na ho, pipeline Instagram ko "content pack" artifact ke zariye manual post karne ke liye already support karta hai.
